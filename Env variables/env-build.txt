# ==============================================================================
# GITHUB ACTIONS DOCKER BUILD-TIME ENVIRONMENT VARIABLES (env-build.txt)
# ==============================================================================
# These variables are passed as `--build-arg` / `ENV` during `docker build` in
# GitHub Actions CI pipelines.
# - Backend services only need dummy/placeholder `DATABASE_URL` & `DIRECT_DATABASE_URL`
#   so `prisma generate` succeeds without connecting to a live database.
# - Frontend Next.js services (`web`, `panels`, `rm-distributors`) inline
#   `next.config.*` rewrites and `NEXT_PUBLIC_*` variables into the static
#   client bundle during `next build`.
# ==============================================================================

## 1. Backend Services Build-Time Variables (`auth-service`, `payments-service`, `stocks-service`, `ticketing-service`)
NAME                                        REQUIRED    DEFAULT / CI BUILD VALUE                                    SERVICES USING IT                                                       DESCRIPTION
DATABASE_URL                                Yes         postgresql://placeholder:placeholder@localhost:5432/db      auth-service, payments-service, stocks-service, ticketing-service       Required by `prisma.config.ts` and `schema.prisma` during `prisma generate` at image build time. A placeholder URI works.
DIRECT_DATABASE_URL                         Yes         postgresql://placeholder:placeholder@localhost:5432/db      auth-service, payments-service, stocks-service, ticketing-service       Referenced in `datasource.directUrl` in `packages/db-unlisted-stox/prisma/schema.prisma`; required during `prisma generate`. A placeholder URI works.
TICKETING_DATABASE_URL                      Optional    postgresql://placeholder:placeholder@localhost:5432/db      ticketing-service                                                       Declared as `ARG`/`ENV` in `apps/ticketing-service/Dockerfile` builder stage alongside `DATABASE_URL`.
PUPPETEER_SKIP_CHROMIUM_DOWNLOAD            Optional    true (Already defaulted in Dockerfile)                      stocks-service                                                          Skips downloading bundled Chromium during `pnpm install` in `stocks-service` (uses Alpine `/usr/bin/chromium-browser`).
PUPPETEER_SKIP_DOWNLOAD                     Optional    true (Already defaulted in Dockerfile)                      stocks-service                                                          Skips Puppeteer browser binary download during `pnpm install` in `stocks-service`.


## 2. Shared Frontend Next.js Build-Time Variables (`web`, `panels`, `rm-distributors`)
NAME                                        REQUIRED    DEFAULT / K8S BUILD VALUE                                   SERVICES USING IT                                                       DESCRIPTION
NODE_ENV                                    Yes         production                                                  web, panels, rm-distributors                                            Enables production optimizations, `compiler.removeConsole` in `next.config.*`, and internal K8s/Docker service rewrite resolution.
NEXT_TELEMETRY_DISABLED                     Optional    1 (Already defaulted in Dockerfiles)                        web, panels, rm-distributors                                            Disables Next.js telemetry during `next build`.
BACKEND_ORIGIN                              Optional    '' (or internal K8s gateway URL, e.g. http://nginx:80)      web, panels, rm-distributors                                            When set at build time, routes all Next.js `/api/*` (and `/storage/*` in `panels`) rewrites through `${BACKEND_ORIGIN}` instead of individual service URLs.
AUTH_SERVICE_URL                            Optional    http://auth-service:3002                                    web, panels, rm-distributors                                            Build-time rewrite destination in `next.config.*` for `/api/auth/:path*` when `BACKEND_ORIGIN` is not set.
STOCKS_SERVICE_URL                          Optional    http://stocks-service:3003                                  web, panels, rm-distributors                                            Build-time rewrite destination in `next.config.*` for `/api/stocks/*`, `/api/orders/*`, `/api/baskets/*`, and related stock routes when `BACKEND_ORIGIN` is not set.
TICKETING_SERVICE_URL                       Optional    http://ticketing-service:3001                               web, panels                                                             Build-time rewrite destination in `next.config.js` for `/api/tickets/:path*` and `/api/labels/:path*` when `BACKEND_ORIGIN` is not set.
STORAGE_SERVICE_URL                         Optional    http://storage-service:3005                                 web, panels                                                             Build-time rewrite destination in `next.config.js` for `/api/storage/:path*`, `/api/upload/:path*`, and `/storage/:path*` when `BACKEND_ORIGIN` is not set.
PAYMENTS_SERVICE_URL                        Optional    http://payments-service:3004                                web                                                                     Build-time rewrite destination in `apps/web/next.config.js` for `/api/payments/:path*` when `BACKEND_ORIGIN` is not set.
NEXT_PUBLIC_PAYMENTS_SERVICE_URL            Optional    /api                                                        web                                                                     Client-side base URL for `paymentsApi` (keep as `/api`).
NEXT_PUBLIC_AUTH_SERVICE_URL                Optional    /api                                                        web, panels                                                             Client-side base URL for `authApi` (keep as `/api` in K8s so browser requests use same-origin Next.js/Ingress proxy routes).
NEXT_PUBLIC_STOCKS_SERVICE_URL              Optional    /api                                                        web, panels                                                             Client-side base URL for `stocksApi` (keep as `/api` in K8s so browser requests use same-origin Next.js/Ingress proxy routes).
NEXT_PUBLIC_TICKETING_SERVICE_URL           Optional    /api                                                        web, panels                                                             Client-side base URL for `ticketingApi`, `adminTicketsApi`, and `supportTicketsApi` (keep as `/api`).
NEXT_PUBLIC_STORAGE_SERVICE_URL             Optional    http://storage-service:3005                                 web, panels                                                             Fallback rewrite URL for `STORAGE_SERVICE_URL` in `next.config.js`.
