# ==============================================================================
# KUBERNETES GLOBAL RUN-TIME SECRET / CONFIGMAP (env-global.txt)
# ==============================================================================
# These environment variables are shared across multiple services at run-time
# and should be stored in a single shared K8s Secret (e.g., `smc-global-env`)
# mounted via `envFrom` before the service-specific secret (`smc-<service>-env`).
#
# IMPORTANT K8S OVERRIDE NOTE:
# - Always list `smc-global-env` FIRST and `smc-<service>-env` SECOND in pod
#   `envFrom` so service-specific variables (like `DATABASE_URL` in
#   `ticketing-service` or `PORT` in each service) cleanly override global ones.
# ==============================================================================
