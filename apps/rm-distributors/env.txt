# BUILD TIME ENVIRONMENT VARIABLES
# Note: In Next.js, `next.config.ts` rewrites and client bundle `process.env.NODE_ENV` checks are evaluated and baked in during `next build`. No `NEXT_PUBLIC_*` variables are used in `rm-distributors` because all client API requests use relative `/api/*` paths via `lib/api-fetch.ts`.
NAME                                        REQUIRED    FALLBACK                                        WHERE USED                                                              DESCRIPTION
NODE_ENV                                    Optional    production (during `next build`)                next.config.ts, Dockerfile, app/error.tsx                               Controls `compiler.removeConsole` (`{ exclude: ['error', 'warn'] }`) in `next.config.ts`, Docker vs local rewrite targets (`isDocker`), and non-production error logging in `app/error.tsx`.
NEXT_TELEMETRY_DISABLED                     Optional    1 (in Dockerfile)                               Dockerfile                                                              Disables Next.js telemetry collection during `next build` and runtime.
BACKEND_ORIGIN                              Optional    ''                                              next.config.ts                                                          When set at build time, routes all `/api/auth/:path*`, `/api/stocks/:path*`, `/api/orders/:path*`, and `/api/health` rewrites through `${BACKEND_ORIGIN}`.
AUTH_SERVICE_URL                            Optional    http://auth-service:3002 (Docker) / http://127.0.0.1:3002 (local)       next.config.ts                                  Build-time rewrite destination for `/api/auth/:path*` when `BACKEND_ORIGIN` is not set.
STOCKS_SERVICE_URL                          Optional    http://stocks-service:3003 (Docker) / http://127.0.0.1:3003 (local)     next.config.ts                                  Build-time rewrite destination for `/api/stocks/:path*`, `/api/orders/:path*`, and `/api/health` when `BACKEND_ORIGIN` is not set.

## 2. Session Cookie Decryption & Route Protection
NAME                                        REQUIRED    FALLBACK                                        WHERE USED                                                              DESCRIPTION
COOKIE_ENCRYPTION_KEY                       Yes*        '' (Passthrough / fails encrypted cookie auth)  proxy.ts                                                                64-character hex key (32 bytes) for AES-256-GCM decryption (`decryptTokenSafe` from `cookie-crypto`) of obfuscated session cookies (`__s_d1` for Distributor, `__s_i1` for Internal RM, `__s_r1` for Distributor RM, `__s_b1` for Branch) in Next.js middleware (`proxy.ts`). (*Must match `COOKIE_ENCRYPTION_KEY` in `auth-service` in production).
